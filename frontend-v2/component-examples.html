Congressional Activity App - Component Examples

Interactive demonstration of the core reusable components

🏛️ CardComponent - Congressional Action Card

The most critical component in the application. Displays congressional actions in a clean, accessible format with legislator photos, bill information, AI-generated summaries, and interactive elements.

🪟 Modal Component - Reusable Modal Container

Fully featured modal with focus trapping, keyboard navigation, accessibility features, and mobile responsive design. Used for onboarding, bill details, member profiles, and other overlay content.
